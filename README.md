# ⬡ AlgoBrainOS (AGOS)

AI-powered DSA learning operating system.

## Quick Start

### 1. Setup Backend
```bash
cd backend
npm install
cp .env.example .env
# Edit .env with your MongoDB URI and Anthropic API key
npm run dev
```

### 2. Open App
Visit: http://localhost:5000

That's it. The backend serves the frontend too.
